# 对于python变量的理解
## 总述
python中，许多类型的变量，就像是钥匙与房间的关系。一些操作的本质是，给一个房间配多把钥匙，亦或者是将一把本来匹配A房间的要是熔掉，重新铸成另一把匹配B房间的钥匙，这当然不改变A房间与可以开A房间的钥匙；而另一些操作的本质是，通过一把钥匙打开房间，将房间重新进行装修，如此一来，所有能打开该房间的钥匙，打开A房间一看，发现里面的妆造焕然一新。
## 可变与不可变
在python中，一些数据类型是不可变的，比如int、float、tuple（当然，元组内的列表可改变）\
而另一批数据自然就是可变的，比如list，dict，以及绝大多数人为class出来的类，比如list我们可以通过append等方法进行操作，使得其房间进行改变。
## define方法对于变量的改变
```python
a=1
def func_1(num):
    print(num)
    num=2
func_1(a)
print(a)
```
这个最终会输出两个1，原因是对于这个func_1而言，相当于它配了一把名为num的钥匙，由于传入参数a，所以这个num和a同时是一个房间1的钥匙\
然后后续num重铸了，变成房间2的钥匙，但这丝毫没有影响到房间1和房间1的钥匙a\
我们再来看下面一段代码：
```python
b=[1,2,3]
def func_2(num_list):
    print(num_list)
    num_list.append(4)
    num_list=[1,2,3]
    print(num_list)
func_2(b)
print(b)
```
这里输出来的结果是[1,2,3]、[1,2,3]和[1,2,3,4],原因是这个func_2配了一把名为num_list的钥匙，它和传入的参数b一样指向同一个房间，所以print这个num_list时，会和原来的b一样为[1,2,3]\
后来这个append操作对于可变的list变量而言，就是打开了这个房间，进行了装修，添加了4，此时b钥匙仍然是这个房间的钥匙，所以后续print这个b时，就会发现是改造过的房间\
然后这个num_list又重铸成另一个房间[1,2,3]的钥匙，和原来那个[1,2,3,4]房间关系断绝，所以此时print是新的[1,2,3]
## 同名变量
对于初学者而言，同名变量管到哪里，是一个十分让人头疼的问题，但是我们上面的两个例子都提到，其实每一个方法本身，在传参的那一刻，都“造了一把钥匙”,而对于一个方法而言，它临时造出来的钥匙，在方法结束后会自动回收，就比如下面一段代码：
```python
a=1
def func_1(a):
    print(a)
    a=2
func_1(a)
print(a)
```
其实这段程序的运行结果和原来的num一摸一样，因为这个我们在调用func_1的时候，只是造出了一把临时的钥匙，叫做a，我们称呼其为局部a，并且局部a所指向的值，和你传入参数（这里是全局a）一样\
而这个局部a，在干完它的工作后会自动消失，在这个func_1里面，你的a都是指这个局部a，你的func_1外面，a则指全局a\
至于全局a会不会被局部a所影响，那必然是要看这个func_1有没有用这个局部a钥匙打开房间，然后装修房间，还是仅仅只是把这个局部a钥匙熔铸了一下而已
